# Cloudflare 서버 만들기 — 처음 하는 분을 위한 안내

**끝까지 하면 약 15분**이고, **돈은 들지 않습니다.** 카드도 등록하지 않습니다.

이 안내는 검은 창(명령 프롬프트)을 한 번도 안 써 보신 분 기준으로 썼습니다.
중간에 막히면 그 화면을 캡처해서 보내 주세요.

---

## 0단계 — Node.js 가 깔려 있는지 확인

**① 명령 프롬프트 열기**

- 키보드에서 **윈도우 키**를 누릅니다
- `cmd` 라고 칩니다
- **명령 프롬프트** 를 클릭합니다

검은 창이 뜹니다. 이 창에 글자를 치고 **Enter** 를 누르면 명령이 실행됩니다.

**② 확인**

아래를 치고 Enter:

```
node --version
```

- `v24.21.0` 처럼 나오면 → **1단계로 갑니다**
- `'node'은(는) 내부 또는 외부 명령...` 이 나오면 → [nodejs.org](https://nodejs.org) 에서
  **LTS** 를 받아 설치하고, 컴퓨터를 다시 시작한 뒤 다시 확인하세요

## 1단계 — Cloudflare 가입

**① 가입**

[dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) 에 들어갑니다.

- 이메일과 비밀번호를 넣고 **Sign Up**
- 메일함에서 인증 메일의 링크를 클릭합니다

> 가입할 때 요금제를 고르라고 나오면 **Free** 를 고르세요. 카드 번호는 넣지 않습니다.
> 도메인을 사라거나 사이트를 추가하라고 나오면 **건너뛰어도 됩니다.** 우리는 도메인이 필요 없습니다.

창 왼쪽에 `C:\Users\Kasiu\Documents\qr-mission\server>` 라고 바뀌면 성공입니다.

## 3단계 — Cloudflare 에 로그인

```
npx wrangler login
```

- 처음이면 `Ok to proceed? (y)` 를 물어봅니다 → **y** 를 치고 Enter
- 브라우저가 저절로 열립니다 → **Allow** (또는 **허용**) 버튼 클릭
- 검은 창에 `Successfully logged in` 이 나오면 성공입니다

> 브라우저가 안 열리면, 검은 창에 나온 긴 주소를 복사해서 직접 열면 됩니다.

---

## 4단계 — 데이터베이스 만들기

```
npx wrangler d1 create qr-mission
```

조금 기다리면 이런 내용이 나옵니다:

```
[[d1_databases]]
binding = "DB"
database_name = "qr-mission"
database_id = "a1b2c3d4-5e6f-7890-abcd-ef1234567890"
```

**`database_id =` 뒤의 따옴표 안 글자를 복사하세요.** (위 예시의 `a1b2c3d4-...` 부분)

### 복사한 값 넣기

1. 파일 탐색기로 `C:\Users\Kasiu\Documents\qr-mission\server` 폴더를 엽니다
2. **`wrangler.toml`** 파일을 **메모장**으로 엽니다
   (파일 오른쪽 클릭 → 연결 프로그램 → 메모장)
3. 이 줄을 찾습니다:

```
database_id = "여기에-받은-ID를-넣으세요"
```

4. 따옴표 **안의 글자만** 복사한 값으로 바꿉니다:

```
database_id = "a1b2c3d4-5e6f-7890-abcd-ef1234567890"
```

5. **Ctrl + S** 로 저장하고 메모장을 닫습니다

> ⚠️ 따옴표 `"` 는 지우지 마세요. 안쪽 글자만 바꾸는 겁니다.

---

## 5단계 — 표 만들기

```
npx wrangler d1 execute qr-mission --remote --file=./schema.sql
```

- `Ok to proceed?` 를 물어보면 **y** 를 치고 Enter
- 끝에 `Executed ... commands` 비슷한 문구가 나오면 성공입니다

---

## 6단계 — 비밀번호 두 개 넣기

**① 관리자 키** — 통계를 볼 때 쓰는 비밀번호입니다.

```
npx wrangler secret put ADMIN_KEY
```

입력하라고 나오면 **길고 추측하기 어려운 글자**를 치고 Enter.
예: `diana-2026-wianbu-stats-7391`

> 치는 동안 화면에 아무것도 안 보입니다. **정상입니다.** 그대로 치고 Enter 하세요.
> **이 값을 어딘가에 적어 두세요.** 나중에 관리자 화면에서 씁니다.

**② 운영요원 확인 번호** — 리워드를 줄 때 운영요원이 누르는 번호입니다.

```
npx wrangler secret put STAFF_PIN
```

4자리 숫자를 치고 Enter. 예: `4821`

> 위안부 전시는 리워드가 없어서 이 값을 안 써도 되지만, 넣어 두면 나중에 박인환에 그대로 씁니다.

## 7단계 — 올리기

```
npx wrangler deploy
```

끝나면 이런 주소가 나옵니다:

```
https://qr-mission-api.여러분계정.workers.dev
```

**이 주소를 복사해서 적어 두세요.** 가장 중요한 값입니다.

브라우저 주소창에 7단계의 주소 뒤에 `/api/health` 를 붙여서 들어갑니다:

```

```

이렇게 나오면 **서버가 살아 있는 겁니다.** 🎉

## 9단계 — 전시 페이지에 연결

1. 파일 탐색기로 `C:\Users\Kasiu\Documents\qr-mission\config` 폴더를 엽니다
2. **`wianbu.json`** 을 메모장으로 엽니다
3. 아래 부분을 찾습니다 (파일 거의 끝쪽에 있습니다):

```json

    "baseUrl": "",
```

4. 빈 따옴표 안에 7단계 주소를 넣습니다:

5. **Ctrl + S** 로 저장
6. **GitHub Desktop** 에서 **Commit** 하고 **Push origin**

1~2분 뒤부터 서버에 기록이 쌓입니다.

## 막혔을 때

| 증상 | 해결 |
|---|---|
| `npx` 를 못 찾는다고 나옴 | Node.js 가 안 깔렸습니다. 0단계로 |
| `wrangler login` 에서 브라우저가 안 열림 | 검은 창의 긴 주소를 복사해 직접 열기 |
| `database_id` 오류 | 4단계에서 따옴표 안 글자만 바꿨는지 확인 |
| 배포는 됐는데 `/api/health` 가 404 | 주소 끝에 `/api/health` 를 정확히 붙였는지 확인 |
| 관리자 화면에 "권한이 없습니다" | 관리자 키가 6단계에서 넣은 값과 다릅니다 |
| 전시 페이지가 서버에 저장을 안 함 | 9단계 후 **Push** 했는지, `baseUrl` 끝에 `/` 를 안 붙였는지 확인 |

## 나중에 고칠 때

| 하고 싶은 것 | 명령 |
|---|---|
| 서버 코드 고친 뒤 다시 올리기 | `npx wrangler deploy` |
| 관리자 키 바꾸기 | `npx wrangler secret put ADMIN_KEY` |
| 기록을 직접 꺼내 보기 | `npx wrangler d1 execute qr-mission --remote --command "SELECT * FROM messages"` |
| 전시 끝나고 데이터 지우기 | `npx wrangler d1 execute qr-mission --remote --command "DELETE FROM messages"` |
