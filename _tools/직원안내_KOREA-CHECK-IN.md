# KOREA CHECK-IN — 직원이 선물 건넬 때

스탬프 다섯 개를 모은 손님은 **「READY TO CHECK-OUT」** 화면을 들고 옵니다.
화면 아래 큰 단추에는 「아직 누르지 마세요」라고 적혀 있습니다 — 손님이 눌러도
아무 일도 일어나지 않고, 직원을 불러 달라는 말만 뜹니다. **끝내는 것은 직원입니다.**

## 완료 처리하는 법

1. 손님 휴대폰 화면 **오른쪽 위 「Imagine your Korea」** 를 **세 번** 톡톡톡 누릅니다
   (천천히 누르면 안 됩니다 — 1.5초 안에 세 번)
2. **「관리자 확인」** 창이 뜹니다
3. 여섯 자리 **확인코드**를 넣고 **✓** 를 누릅니다
4. 선물을 건네 주세요

누르는 자리는 보이지 않습니다. 손님에게는 그냥 로고입니다.

## 그 뒤로 일어나는 일

- 카드가 **투명해지고 「완료」 표**가 찍힙니다
- 「선물은 한 번만 받을 수 있습니다」 라는 안내가 손님 말로 함께 뜹니다
- 같은 휴대폰으로 **두 번은 안 됩니다.** 다시 코드를 넣으면
  「이미 완료 처리된 카드입니다」 라고만 나옵니다
- 남은 6·7번 스탬프는 그대로 이어서 모을 수 있습니다

## 확인코드

코드 숫자는 **이 저장소 어디에도 적혀 있지 않습니다.** 홈페이지 파일은 누구나
열어 볼 수 있어서, 흩뜨린 값(`config/kcheckin.json` 의 `admin.codeKey`)만 둡니다.
숫자는 따로 전달받은 것을 쓰세요.

코드를 바꿀 때는

```bash
node _tools/admin-code.js 123456
```

나온 값을 `config/kcheckin.json` 의 `admin.codeKey` 에 넣고 올리면 됩니다.

> 여섯 자리는 백만 가지뿐이라, 작정하고 하나씩 맞혀 보면 뚫립니다.
> **자물쇠가 아니라 눈에 안 띄게 하는 울타리**입니다. 선물은 직원이 직접
> 건네므로 코드가 새더라도 손님이 얻을 것은 없습니다. 다만 **코드를 화면에
> 띄운 채 손님에게 휴대폰을 돌려주지는 마세요.**

## 한 휴대폰으로 계속 시험해 보기

시연·점검 때 같은 휴대폰으로 처음부터 다시 해 보려면,

1. 「Imagine your Korea」 **세 번** 누르기
2. 확인코드 넣고 **✓**
3. 창 아래에 생기는 **「시험용 — 이 휴대폰 기록 지우기」** 누르기
4. **한 번 더** 누르면 지워집니다 (손이 스쳐 손님 기록을 날리지 않게 두 번 묻습니다)

지우면 첫 화면으로 돌아가고, 스탬프·이름·완료 표가 모두 없어집니다.
이 단추는 **코드가 맞아야 보입니다.** 손님은 볼 수 없습니다.

기록은 그 휴대폰 브라우저에만 있으므로, 다른 손님에게는 아무 영향이 없습니다.
